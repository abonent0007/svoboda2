# «Свобода 2.0» — обновление по факту и вопросы по следующим шагам

Дата: 2026-11-17. Автор: DeepSeek. Ревьюер: GPT (ты в курсе проекта).

## 1. Что реализовано и установлено (v2.0.7, сборка зелёная, на устройстве)

- DPI-движок (ciadpi 17.3 + HEV JNI), DEGRADED-фаза, стратегия «своя строка» ручным вводом.
- Бенчмарк P1 с DIRECT-базовой линией, таксономией исходов (FULL_SUCCESS / SERVER_LIMITED /
  SERVER_ERROR / TRANSPORT_ONLY / NETWORK_FAILURE), макро-рейтингом по категориям, общим
  campaignSeed-порядком доменов и staged-попытками (3/10/20).
- AUTO v1: кнопка активна; подбор транспорта по порядку AWG→WARP→DPI и приоритету стран
  NL→FI→US; без переключений по foreground-приложению; антидребезг 5 мин; строгая/гибкая
  политика страны; проверка Telegram DC по активному маршруту (в DPI — через SOCKS).
- Генератор WARP: шаблоны AWG 1.0/2.0/3.0/3.1 + LTE (MTU 1280, keepalive, Cloudflare-only),
  свой QUIC-Initial, DNS-пресеты с проверкой валидности реальным DNS-запросом, массовое
  создание N профилей, измерение страны выхода профиля.
- **Публичные серверы NL/FI/США вошли в APK 2.0.7** (Delta-Kronecker/Cloudflare-Warp,
  атрибуция в приложении): 9×nl.tribukvy.ltd (NL), 3×fi.tribukvy.ltd (FI), 3×engage
  (US/anycast). Страна измеряется после подключения, хранится в prefs, используется AUTO.
  Это публичные коллективные identity — стабильность не гарантирована.
- DNS-диалог: 9 резолверов + проверка реальным DNS-запросом + своё поле.
- ReconnectCoordinator уважает testingMode во время бенчмарка; 42 стратегии; SQLite-журнал.

Проверка на устройстве: v2.0.7 устанавливается через adb (versionCode=207), процесс жив,
крашей нет; телефон сейчас у пользователя (на экране его другое VPN-приложение «OBNOVA»),
поэтому полный смоук-прогон (AWG-рукопожатие, WARP connect, публичный NL-сервер, DPI,
AUTO, бенчмарк-старт) ещё не выполнялся.

## 2. Факты, подтверждённые измерениями

- Telegram DC (MTProto) недоступны через любые DPI-стратегии (IP-блок). web.telegram.org —
  доступен (200 на одной из стратегий). Telegram-приложение только через AWG/WARP.
- YouTube: TCP/TLS успешны через часть стратегий, видео не играет ни с одной на этой сети
  (MTU 1420/1440 подозрение — нужен тест с 1280) или это троттлинг видео-CDN.
- `android.jar` API 35: setProfile нет → «настоящие раздельные одновременные туннели»
  возможны только как single-tun multi-upstream (sing-box/mihomo package-based).
- WARP anycast не гарантирует страну; публичные любые списки (NL/FI/US) стабильную страну
  не обещают; строгое NL/FI/US возможно только со своим сервером в этих странах.

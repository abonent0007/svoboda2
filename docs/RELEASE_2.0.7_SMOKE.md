# RELEASE 2.0.7 — Smoke-тест (по чеклисту GPT)

Дата: 2026-11-17. Устройство: Realme RMX3370, Android 13 (`97db202c`). Версия: 2.0.7 (versionCode 207).
Цель: зелёный smoke-прогон P0→P3, затем ревью и публикация (только по отдельному подтверждению).

Как выполнять: не занимать телефон другим трафиком (YouTube/игры/крупные загрузки), режим «Полёт»
не включать; телефон на зарядке или >40% батареи; перед каждым этапом — отключать предыдущий VPN.

## A. Базовая работоспособность
- [ ] Приложение запускается без краша; нативные библиотеки загружены (`adb logcat -d -v brief | grep -iE 'FATAL|AndroidRuntime|UnsatisfiedLink'` пуст)
- [ ] Все четыре режима отображаются: AWG / WARP / DPI / AUTO
- [ ] Состояние соединения отображается корректно (ПОДКЛЮЧЕНО/ОТКЛЮЧЕНО/…)
- [ ] Ping обновляется; FGS-уведомление при подключении появляется и исчезает при отключении
- [ ] onRevoke (отключить VPN в настройках Android во время работы): все движки остановлены, процессы `ciadpi`/туннеля отсутствуют
- [ ] Повторный запуск после kill восстанавливает сохранённые настройки (способ подключения, стратегия)
- [ ] НЕТ зависших процессов и уведомлений после остановки

- [ ] Неверный .conf отклоняется без краша (валидатор)

- [ ] Запуск ciadpi: `ps` показывает `libbyedpi.so -…` с вашими аргументами
- [ ] SOCKS5 слушает 127.0.0.1:1080 (`adb shell netstat -tlnp | grep 1080`)
- [ ] HEV получает TUN fd (лог: `Bringing tunnel UP`, `Established`)

- [ ] Рабочая стратегия восстанавливается после перезапуска (`connection_method=DPI_DIRECT` + ваша строка)
- [ ] Пользовательская стратегия имеет приоритет над каталогом
- [ ] Неверные аргументы отклоняются (проверка argv в UI)
- [ ] AWG/WARP после работы DPI остаются работоспособными (нет сломанного состояния)
- [ ] Отключение закрывает HEV и ciadpi (процессов нет; SOCKS не слушает)
- [ ] Повторное подключение не создаёт второй процесс ciadpi
- [ ] Падение ciadpi (kill процесса вручную) — приложение уходит в ERROR, не создаёт бесконечный перезапуск

- [ ] Публичные серверы участвуют в AUTO ТОЛЬКО при галочке «Публичные серверы в AUTO» (default выкл)

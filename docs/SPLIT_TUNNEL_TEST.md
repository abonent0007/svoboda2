# Этап 2 — Раздельная маршрутизация на SIM (план и критерии)

Дата: 2026-11-17. Устройство: Realme RMX3370 (Android 13), `97db202c`.
**Статус:** заблокирован до восстановления USB-отладки (`adb devices` пуст).

## Условия теста

- [ ] Только SIM, без Wi-Fi (DurDom2 не использовать — пакет excluded ломается)
- [ ] Method = WARP (не AUTO — чтобы маршрутизация не мешалась с переключением транспорта)
- [ ] Включён пресет «Российские приложения — напрямую» (banks/gov/web-local через ExcludedApplications)
- [ ] Остальной трафик идёт через VPN

## Шаги

1. Установить connection_method=WARP, force-stop, relaunch.
2. Открыть меню → «Российские приложения — напрямую» → убедиться, что все переключатели ON.
3. Подключиться (ПОДКЛЮЧЕНО + ping не «—» мс).
4. Проверить приложения: Сбербанк, Т-Банк, Альфа-Банк, Госуслуги, Почта России (5 приложений):
   - запускаются;
   - работают (основной экран открыт / приложение отвечает);
5. Проверить, что наш трафик через туннель: `ip route get 1.1.1.1 uid 10328` → должен отличаться от direct;
   `NetProbe` приложение и раундбанк (?) — показывать, что банки не идут через туннель.
6. Проверить, что excluded приложения в VPN не идут: на основе `ip rule show` + `ip route get <ip банка> uid <банк-uid>`
7. Отключить VPN полностью (ОТКЛЮЧИТЬ) → банковские приложения продолжают работать (в любом случае это проверка
   их независимости от туннеля — но для split-tunnel это недостаточное доказательство).
8. Переподключить VPN → настройки не теряются (excluded приложения всё ещё excluded).
9. IPv6: проверить, не идут ли исключённые приложения через туннель по IPv6.
10. Отключить пресет → обратное подключение → exclude-пакеты уходят В туннель (control).

## Определения итогов (для каждого приложения)

- `APP_FUNCTIONAL` — приложение запускается и показывает рабочий экран;
- `DIRECT_ROUTE_CONFIRMED` — доказан выход мимо VPN (маршрут из исключений);
- `TUNNEL_ROUTE_CONFIRMED` — доказан выход через VPN (туннель);
- `UNKNOWN` — приложение работает, но маршрут не подтверждён.

## Не подтверждаем без измерений
- «Приложение работает» ≠ «Direct подтверждён».
- Общие CDN/пересечение IP-диапазонов учесть (некоторые банки сидят за теми же CDN — списки `ExcludedApplications`
  действуют именно по пакетам, поэтому маршрутизация из exceptions — гарантированна, а клинически CDN-перекрытие
  не имеет значения для этого механизма). Примечание: по каким доменам трафик — нужны дополнительные измерения.

## Замечание по IPv6
- К пропущенному через VPN и напрямую через split — русская direct list по пакетам идёт НЕ в VPN, значит IPv6 банки
  также идут напрямую (правило простое: они не включены в VPN и для них нет IPv6 в туннеле).
- Проверить: после отключения VPN/подключения — эти приложения продолжают работать (всякая конфигурация должна работать
  для DIRECT, даже если VPN сломан).

# Offline rollback (Свобода 2.0)

Если новое обновление сломало подключение, откатитесь на предыдущий APK
без интернета и без GitHub.

## 1. Подготовка (один раз)
Сохраните старые APK в папку устройства, например `/sdcard/Download/svoboda2-history/`:
- `app-arm64-v8a-release.apk` (или universal)
- при необходимости `app-arm64-v8a-debug.apk` только для диагностики, не для продакшена.

## 2. Откат на устройстве
1. Отключите интернет (режим полёта) — чтобы автообновление не сработало.
2. Откройте файловый менеджер, запустите сохранённый APK.
3. Android покажет «Приложение уже установлено» → «Обновить» (или «Установить»).
   Подпись должна совпадать с установленной — иначе сначала удалите приложение
   (настройки/профили при этом сбросятся).
4. После установки запустите приложение и проверьте подключение.

## 3. Через adb (если экран недоступен)
```
adb install -r -d app-arm64-v8a-release.apk
```
Флаг `-d` разрешает downgrade на debug/старых сборках (только для отладки).

## 4. Отключение автообновления
- Меню → «Обновления» не нажимать; либо отключить интернет при запуске.
- При необходимости очистить `last_good_config` и профили:
  `adb shell run-as svoboda.runet.abonent0007 rm -f files/generated_profiles.json`

## 5. Восстановление настроек
- SharedPreferences: `svoboda2_prefs` (active_server_id, tunnel_mtu, excluded_apps,
  ping_interval_ms, ping_graph_enabled, auto_connect).
- Список серверов: `files/own_servers.json`.
- Сгенерированные профили: `files/generated_profiles.json`.

## 6. Проверка после отката
- Главный экран: статус «ПОДКЛЮЧЕНО», IP/страна/ping обновляются.
- Меню: версия `vX.Y.Z` соответствует установленному APK.
- При необходимости — «Проверить связь».

Никогда не устанавливайте сборки с другой подписью поверх рабочей — Android их отклонит.
Храните приватный ключ релизной подписи (`release.keystore`) в безопасном месте:
без него невозможно выпустить обновление с той же подписью.

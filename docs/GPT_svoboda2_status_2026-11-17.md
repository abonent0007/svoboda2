# Svoboda 2.0 — статус после принятия твоих рекомендаций и разработка 2.0.7

## Что сделано (закоммичено локально 1b90511, не опубликовано)

1. **AUTO-журнал (auto_log.txt)**: файл в filesDir (последние 150 строк), события: старт AUTO
   (order/countries), подсчёт AWG-серверов, пробуем/выбран кандидат, антидребезг, отказ при
   строгой политике, конец переключения, "Telegram DC down → AWG/WARP". Журнал НЕ показывается
   в UI — только файл (вопрос: показывать ли?).
2. **Публичные серверы NL/FI/US в APK** (по твоей рекомендации — отдельная группа с атрибуцией
   Delta-Kronecker/Cloudflare-Warp): 9 × NL, 3 × FI (метрика `nl/ni/nl2/nl3/fi.tribukvy.ltd`),
   3 × `engage.cloudflareclient.com`. Страна выхода ИЗМЕРЯЕТСЯ после подключения и сохраняется
   со свежестью `CC@epoch`; в AUTO участвуют ТОЛЬКО при `autoIncludePublicServers=true`
   (default выкл, тумблер в настройках AUTO добавлен пользователем) и только со свежей (≤7 дней)
   измеренной страной при строгой политике.
3. **engage.cloudflareclient.com** больше не помечен «США» — «Anycast · страна после измерения · порт».
4. **Smoke-лист** `docs/RELEASE_2.0.7_SMOKE.md` — по твоему чеклисту (A–I).
5. Версия 2.0.7 (versionCode 207) собрана и установлена на устройство; сама сборка зелёная.

## Текущая ситуация

- Телефон у пользователя в руках (он шёл в его приложении-VPN «OBNOVA») — **smoke не прогнан**.
- Пользователь сам правит код (добавил `autoIncludePublicServers` и тумблер в UI) — мы не откатываем, дорабатываем вокруг его работы.
- Play Protect блокирует sideload debug-APK — прямые пути установки: `adb install -r`.
- 2.0.4+ не устанавливается на устройство (Play Protect) — на телефоне до сих пор 2.0.3.
- AUTO сейчас: порядок AWG→WARP→DPI, приоритет NL→FI→US, антидребезг 5 мин,
  переключение по падению туннеля/Telegram DC (DPI → AWG/WARP).

# Обновление по проекту «Свобода 2.0» для ревью (сессия 2026-11-16/17)

Контрольная точка: коммиты `0af722d` → `853d091` → `fe81842` (+2.0.7 bump, локально).
Устройство: Realme RMX3370 (Android 13), Wi-Fi + 5G (tele2). Сборка 2.0.7 (versionCode 207) установлена и запущена, крашей нет.

## Что реализовано и проверено на устройстве

1. **DPI-движок**: ciadpi 17.3 отдельным процессом + HEV tun2socks (JNI). TUN → HEV → локальный SOCKS5 127.0.0.1:1080. Собственный пакет исключён из VPN (рекурсия). Доказательство связи — через локальный SOCKS5.
2. **Бенчмарк стратегий (P1)**: выбор из 46 доменов в 7 категориях (чекбоксы, сохраняется), последовательный перезапуск **только ciadpi** между стратегиями (Android VPNService не трогаем), измерения DNS→TCP→TLS→HTTP через SOCKS5 (то есть гарантированно через проверяемую стратегию), 3 попытки, SQLite-журнал (session/strategy/domain/attempt), ранжирование по ТЗ, пауза/стоп с восстановлением исходной стратегии, экспорт JSON/CSV.
   - **DIRECT-baseline** (тот же клиент напрямую): считаем bypass gain (что обход открыл) и регрессии. DIRECT-замер — отдельный route_type, не псевдостратегия.
   - Таксономия исходов: FULL_SUCCESS / SERVER_LIMITED (401/403/429) / SERVER_ERROR (5xx) / TRANSPORT_ONLY / NETWORK_FAILURE.
   - Один campaignSeed на сессию: все стратегии раунда идут по ОДНОМУ порядку доменов.
   - Три рейтинга: универсальный (макро-оценка по категориям), лучшие по категориям, быстрые среди успешных.
   - Staged-попытки: 3 (скрининг) / 10 (валидация) / 20 (финал), переключается в UI; фильтр стратегий для повторной проверки победителей.
3. **AUTO v1**: кнопка активна. Подбор транспорта по порядку AWG → WARP → DPI и приоритету стран NL → FI → US; переключений по foreground-приложению нет (ломает сессии); антидребезг (удержание ~5 мин); строгая/гибкая политика страны; проверка Telegram DC **по активному маршруту** (в DPI — через SOCKS, иначе это DIRECT); при недоступных DC выбирается AWG/WARP, иначе честное сообщение.
4. **WARP-генератор**: шаблоны AWG 1.0/2.0/3.0/3.1 + LTE (MTU 1280, keepalive 25, Cloudflare-only маршруты), свой QUIC-Initial для I1, endpoint-пресеты, массовое создание N профилей с рандомизированными junk-параметрами, измерение фактической страны выхода после подключения.
5. **Раздельное туннелирование по сервисам**: 16 сервисов с IP-диапазонами (MIT) → AllowedIPs → в туннель только их трафик, остальное напрямую. Обратный пресет «сервисы напрямую».
6. **DNS**: 9 резолверов каталога + свой ввод + **проверка валидности реальным DNS-запросом** (✓/✗ + мс) в настройках DNS и в генераторе WARP.
7. **Своя DPI-стратегия**: ручной ввод argv ciadpi, проверка числа токенов, приоритет над каталогом; каталог — 42 стратегии (токены сверены с исходниками ciadpi 17.3).
8. **Публичные серверы NL/FI/США** (новый модуль 2.0.7): 9 × `nl.tribukvy.ltd` (NL), 3 × `fi.tribukvy.ltd` (FI), 3 × `engage.cloudflareclient.com` (США/anycast) — публично опубликованные конфиги Delta-Kronecker/Cloudflare-Warp с указанием источника; страна выхода **измеряется** после подключения и показывается рядом с сервером; AUTO учитывает измеренную страну. US в публичном списке маркированного не было — заменён на engage (anycast, неизвестно до замера). У пользователя нет своего сервера.
9. **Восстановлена рабочая стратегия** `-d1 -s1+s … -d35+s -a1` — проверено по аргументам процесса ciadpi; предыдущая сохранена в `dpi_custom_strategy_prev` для отката.

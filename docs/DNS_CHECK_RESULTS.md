# «Свобода 2.0» — DNS-проверка 9 резолверов (2026-11-17)

Транспорт при тесте: **WARP (candidate через AUTO, tun0 <POINTOPOINT>, IPv6-туннель
2606:4700:110:...)**. Собственный пакет приложения исключён из VPN — поэтому
**прямые DNS-запросы приложения идут напрямую**, в обход туннеля (наш собственный пакет
разрешён). Это значит, что Russian-community резолверы (geodema/comss/mafioznik), которые
требуют прямого подключения от RU-оператора, из US-PoP-выхода видны как «не отвечают» —
не сетевая ошибка приложения, а честный ответ этих резолверов через тот маршрут.

## Что подтверждено/чего нет

- Подтверждено: текст статуса читается прямо с экрана проверки в приложении — приложение
  действительно делает замер (через свои адреса из каталога для knownIps, через системный
  DNS для остальных).
- Не подтверждено (и это ожидаемо): «через системный DNS» или «через какой из двух адресов
  ответ пришёл» — приложение выводит одну финальную строку, не раскрывая источник.
  Полный ответ с трассировкой потребовал бы packet-capture вне приложения.
- Исходный выбор DNS (dnsServers = пусто = default 1.1.1.1) не изменён — кнопка «ВЫБРАТЬ»
  ни для одного резолвера не нажималась.
- Примечание: через DPI-маршрут (RU-exit) geodema/comss/mafioznik могут отвечать —
  тогда провал связан с маршрутом WARP, а не с резолверами. Это проверяется отдельно,
  когда придёт время теста через DPI.
